# CGS2531 Excel Projects

Selected Excel work from UF's CGS2531 (Problem Solving Using Computers).

| File | What it shows |
|---|---|
| `Statistics_Descriptive_Histograms.xlsx` | Descriptive statistics, outlier removal, and histograms on willingness-to-pay survey data |
| `Excel_Regression_House_Price.xlsx` | Simple linear regression (sale price vs. living space), manual calculation checked against the Data Analysis ToolPak |
| `Regression_Income_vs_Rent.xlsx` | Regression of monthly rent on income, descriptive statistics, ToolPak summary, chart |
| `Pivot_Tables_Survey.xlsx` | Three PivotTables summarizing a student survey |
| `Simple_Data_Analysis_Budget.xlsx` | Monthly expense comparison with VLOOKUP, sorting, and charts |
| `Weighted_Decision_Matrix_Car_Purchase.xlsx` | Weighted decision-making matrix comparing three cars (musts/wants, weighted scores, results chart) |
